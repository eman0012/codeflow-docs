# Contact

CodeFlow is an open-source project. The most useful way to reach the team depends on what you need.

## Bug Reports and Feature Requests

File an issue on the project repository:

- **GitHub Issues:** [github.com/eman0012/codeflow-docs/issues](https://github.com/eman0012/codeflow-docs/issues)

When filing a bug, include:

- The CodeFlow version (`codeflow --version`)
- A minimal reproduction of the drift rule that's misbehaving
- The relevant section of your `codeflow.yaml`
- Expected behaviour and actual behaviour

## Documentation Corrections

If something on this site is wrong, outdated, or unclear, the fastest path is to open a pull request against the docs repository. Every page on this site has an "Edit this page" link at the bottom that takes you directly to the source on GitHub.

## Project Discussions

For broader questions — design decisions, integration patterns, comparison with other tools — use GitHub Discussions on the project repository.

## Contributing

CodeFlow welcomes contributions. Before opening a pull request:

1. Open an issue describing the change you want to make
2. Wait for confirmation that the change fits the project's direction
3. Fork the repository and create a branch from `main`
4. Open the pull request with a clear description of what changed and why

Smaller fixes (typos, broken links, documentation corrections) skip step one — open the PR directly.
