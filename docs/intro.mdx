# Getting Started with CodeFlow

This guide walks through configuring CodeFlow for an existing repository. Setup takes about 15 minutes for a project of moderate size.

## Prerequisites

Before starting, confirm the following:

- Node.js version 18 or higher is installed
- Your project is in a Git repository
- Your documentation lives in Markdown files
- You have write access to the repository's CI configuration

## Installation

Install CodeFlow globally via npm:

```bash
npm install -g codeflow
```

Verify the installation by checking the version:

```bash
codeflow --version
```

## Initialize Your Repository

Navigate to your repository's root and run:

```bash
codeflow init
```

This creates a `codeflow.yaml` configuration file at the project root and a `.codeflow/` directory for CodeFlow's internal state.

:::note
Add `.codeflow/` to your `.gitignore`. The directory contains cached scan results that don't need to be committed.
:::

## Define Source-to-Doc Mapping

Open `codeflow.yaml` and tell CodeFlow which source files map to which documentation files:

```yaml
sources:
  - path: src/api/
    docs: docs/api-reference.md
    watch:
      - "*.ts"
      - "*.js"

  - path: src/cli/
    docs: docs/cli-commands.md
    watch:
      - "*.go"
```

## Run Your First Scan

```bash
codeflow scan
```

CodeFlow compares the current state of the source files against its baseline and reports any drift. The first scan establishes the baseline; subsequent scans compare against it.
